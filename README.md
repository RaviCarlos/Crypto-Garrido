# 🔒 SecureCore Enterprise - Simulador de Criptografia com Árvores AVL

> Projeto desenvolvido como parte da disciplina de Engenharia de Software da Universidade de Vassouras, focado em um sistema de criptografia/descriptografia de mensagens utilizando a estrutura de dados de Árvores AVL.

---

## 📋 Sobre o Projeto
O **SecureCore Enterprise** é uma aplicação simuladora voltada para a proteção e envio seguro de dados entre filiais corporativas. O diferencial técnico do projeto é a utilização de **Árvores AVL** (Árvores Binárias de Busca Auto-balanceadas) para manipular e transformar o fluxo de caracteres de forma eficiente, garantindo complexidade temporal otimizada e estabilidade nas operações.

---

## ✨ Funcionalidades Principais
* **Motor de Criptografia AVL:** Utiliza os percursos e o balanceamento de nós da árvore para cifrar e decifrar blocos de texto.
* **Visualização em Tempo Real:** Interface interativa que permite acompanhar o comportamento da árvore e o fluxo dos dados.
* **Exportação e Compatibilidade:** Geração automática de arquivos executáveis `.bat` com os dados processados.
* **Integração de Comunicação:** Opção de envio rápido dos dados criptografados via E-mail e WhatsApp.
* **Tratamento de Exceções:** Sistema robusto de alertas para validação de entradas, arquivos corrompidos e prevenção de erros do usuário.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS3 e JavaScript (para a interface web e lógica de manipulação local).
* **Estrutura de Dados:** Árvores AVL (Auto-balanceada com fator de balanceamento estrito $\le 1$).
* **Hospedagem / Deploy:** GitHub Pages.
* **Gerenciamento de Projeto:** Metodologia Ágil (Scrum/Kanban via Trello).
